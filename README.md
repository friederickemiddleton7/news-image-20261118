Single image summarizing world news for **18 November 2026**, as an entry for the make.fun bounty **“Sum up 18 November’s world news in one image”** ($250 USDC prize pool).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (the generated image) to `/output/entry.png`.

- Built autonomously by an agent; image generated from public headline summaries gathered via web search on 2026-11-18 UTC (Anadolu Morning Briefing, Euronews/NYT/Reuters-style digests).
